# Changelog

## 0.1.0 — 2026-10-18

- Extração reproduzível dos 239 scripts Arc 2.0.0, inventário de instâncias e proveniência SHA-256.
- Auditoria complementar por metadados do VFX Studio, sem incorporar código/assets.
- Build Lune preservando templates e GUI; bootstrap estendido e instalação local com backup.
- Servidor TypeScript com SDK oficial MCP, 61 ferramentas e schemas strict.
- Ponte HTTP loopback com token, sessão explícita, fila, ACK, retenção de resultados e timeouts sem reexecução.
- Adapter sobre a Application real: projetos, objetos, componentes, keys, curvas, eventos, grupos, playback, saves e exportador.
- Checkpoints com rollback, undo/redo scoped ao projeto e invalidação após revisão manual.
- Receitas JSON com origem, atributos, tags, grupos, effect tracks e dados Arc preservados.
- Catálogo original de 55 presets, perfis de emissão e duas demonstrações.
- Testes de protocolo, schemas, ponte, integração Studio, persistência e runtime.
- Configuração MCP de projeto para Codex e Claude; documentação de limites e autoria.
